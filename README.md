# Explainable-AI-Medical-Diagnosis
An Explainable AI framework for medical diagnosis using machine learning models and interpretability techniques such as SHAP and LIME.
## Overview

Machine learning models can achieve high predictive performance, but their decisions are often difficult to interpret. This project focuses on developing an interpretable medical diagnosis system that provides both predictions and explanations.

The framework trains machine learning models and uses explainability methods to understand which features influence model decisions.

## Objectives

- Develop machine learning models for medical diagnosis
- Compare different classification algorithms
- Apply Explainable AI techniques
- Interpret model predictions using SHAP and LIME
- Generate human-understandable explanations
